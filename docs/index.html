An editor that feels like home.

Tau brings the fun back into writing code. It is a fast, calm desktop editor that puts your ideas first — so you can explore, experiment, and ship without the noise of a heavy IDE.

Get the code on GitHub
terminal 
$ git clone https://github.com/martinsk/tau.git
$ cd tau
$ npm install --prefix frontend
$ npm run dev
